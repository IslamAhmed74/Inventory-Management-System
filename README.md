# 📦 Inventory Management System

A modern and responsive **Inventory Management System** built with **Laravel 12**, **Blade**, **Tailwind CSS**, and **MySQL**.

---

## 🚀 Features

- 🔐 Authentication (Laravel Breeze)
- 👥 Role-Based Access (Admin & User)
- 📊 Dashboard
- 📦 Product Management
- 🏷️ Category Management
- 🚚 Supplier Management
- 👤 User Management
- 📈 Stock In / Stock Out
- 🔍 Search & Pagination
- 📱 Responsive Design

---

## 🛠️ Tech Stack

- Laravel 12
- PHP 8.3+
- Blade
- Tailwind CSS
- MySQL
- Vite
